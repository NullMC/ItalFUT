# ItalFUT visual system

The direction is a contemporary football operations desk: confident editorial headings and restrained, fast-to-scan admin controls rather than an esports aesthetic.

- Deep pine #102f27 for authority and sidebars; pitch charcoal #08231f for hero.
- Field lime #bce56d for meaningful primary CTAs; off-white #f7f8f5 backgrounds, white for work surfaces.
- DM Sans for interface typography; Manrope 800 for expressive but controlled headings.
- Strong composition in the landing hero with an explicitly illustrative dashboard preview.
- Feature list as information architecture, compact admin working rows, and mobile scrollable tournament navigation.
- Organizer-specific accents via one CSS custom property. Accessibility focus rings and reduced-motion support.
- No stock imagery, no copied branding, no fake payment states. Empty, error and locked states are part of the experience.
